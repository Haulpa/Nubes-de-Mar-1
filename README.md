# Mar de nubes · Puerto del Pico
1. Crea un repositorio en GitHub y sube TODO el contenido de esta carpeta (incluida .github).
2. Pestaña Actions → "Build APK" → espera ~3-5 min (o Run workflow).
3. Entra en la ejecución → Artifacts → mar-de-nubes-apk → descarga y descomprime → app-debug.apk.
4. Cópialo al móvil e instálalo (permitir "orígenes desconocidos").
5. Abre la app, acepta notificaciones y desactiva la optimización de batería para la app.
